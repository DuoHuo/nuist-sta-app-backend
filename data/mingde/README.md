# 明德楼七层测试模型

建筑 ID：`OSM-Way862952692`。模型来自用户提供的七张消防疏散图，按现有 OSM 轮廓估算位置、朝向及比例。**这是可供前后端联调的示意模型，不是实测 BIM，也不能作为消防疏散或无障碍通行依据。**

## 文件

- `mingde.glb`：整栋七层 GLB 2.0，所有几何和材质内嵌，无外部资源。
- `mingde-1F.glb` … `mingde-7F.glb`：各层单独 GLB，单层地面归零。
- `manifest.json`：坐标锚点、朝向、楼层标高、节点名与原图来源。
- `mingde-*F.geojson`：对应楼层的 WGS84 面要素，可用于核对和 GIS 检查。
- `import-indoor.sql`：追加楼层、房间、门、墙、POI、导航节点与楼梯跨层边。事务执行；发现已有楼层时拒绝覆盖。
- `validation.json`：模型生成与连通性验证结果。
- `upload-result.json`、`api-validation.json`：上传和接口验收时生成的结果。

## 模型约定

GLB 使用米制、Y 向上。X 沿图纸向右，Z 沿图纸向下；锚点为 `(118.712935, 32.2070539)`，按现有建筑轮廓估算朝向。整栋根节点为 `floor_0` 至 `floor_6`；各层独立 GLB 沿用对应节点名。`level_index=0` 对应 `1F`。

层高假设 3.6 米，墙高 2.8 米，墙厚 0.2 米。楼板厚 0.18 米。整栋是开放剖切形式，便于查看室内；不包含照片未提供的外立面、窗户立面、设备管线、家具和精确楼梯构造。楼梯踏步为示意，导航依据结构化图数据而非网格碰撞。

空间位置、门宽、墙厚、层高与楼梯成本均为估算。图纸没有北箭头或尺寸，朝向、比例需日后用测量控制点校正。原图的合并房间保留为合并房间，不凭空拆成多个教室。

## 图纸中特别保留的差异

- 1F：`N115`、`S103`、`S101`、南侧入口大厅和未标注用房。
- 2F：西北大房间为 `N212-215`。
- 3F、4F：按图分别保留房间编号。
- 5F：南侧西端为 `S506-507`，并非 `S505-506`。
- 6F：南侧东端为屋面；只有 `S603-604`、`S601-602` 两个南侧房间。
- 7F：只有东北局部的 `N701`、`N702`、走廊及东北楼梯，没有复制整层。
- 卫生间图中没有标明性别，命名为卫生间 1 / 2。
- 图示四处楼梯在 1F—6F 连通，仅东北楼梯通往 7F，共 21 条跨层边。图中未提供电梯位置，未编造电梯或跨层无障碍线路。
- 七层西侧门外区域未提供，保留门洞但不生成未知区域或导航连线。

## 重新生成

在后端项目目录执行（Python 需安装 numpy、shapely、trimesh、mapbox-earcut）：

```bash
python scripts/generate_mingde.py
```

生成检查包括 Polygon 有效性、全部 326 个室内节点可从入口到达、同层导航不穿墙。GLB 网格同时经过合并接缝处理。

## 上传 GLB

后端启动且完成迁移后：

```bash
python scripts/upload_mingde.py --base-url http://127.0.0.1:8080
```

若服务启用令牌，通过环境变量 `CAMPUS_COLLECT_TOKEN` 提供。脚本发送整栋模型、manifest 和七个分层 GLB，上传后逐一下载并验证 SHA-256。

管理台建筑档案中也提供“上传模型”和“打开查看器”。GLB 上传更新模型版本，不自动改写房间或导航图。

## 导入结构化室内数据

只在目标明德楼没有室内数据时执行：

```bash
psql "$CAMPUS_DATABASE_DSN" -X -v ON_ERROR_STOP=1 -f data/mingde/import-indoor.sql
```

导入采用已有建筑 ID，保留建筑轮廓和现有室外道路，添加一个估算主入口及室外路网连接。附近没有 40 米内双向步行道路时事务失败，不留下半份数据。入口及相关连接不声明无障碍可达。

**不要重跑 `scripts/import_osm.py` 的全量删除重建流程来更新此模型。** 原流程会级联删除挂在 OSM 建筑上的楼层等数据。

接口验证：

```bash
python scripts/verify_mingde.py --base-url http://127.0.0.1:8080
```

检查七层和 60 个房间、房间 POI/节点关联、同层路线、1F↔7F 六次换层、室外至七层，以及跨层无障碍请求无法通过楼梯。
